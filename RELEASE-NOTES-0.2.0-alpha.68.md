# Flux Reader 0.2.0-alpha.68 — Reader scrub & Library multi-select

В Reader удерживайте и перетаскивайте ползунок процента, отпустите палец для перехода к месту в книге. В Library удерживайте карточку книги для выделения, добавляйте другие книги коротким нажатием, выберите действия в «⋮» наверху. Назад или крестик закрывает режим выделения.

Сборка: `./scripts/selfcheck.command --static`, затем `./FluxReader-0.2.0-alpha.68-build-install.command` с Android SDK и подключенным телефоном.
