# Flux Reader 0.2.0-alpha.33

- Долгое нажатие по книге теперь запускает настоящий режим множественного выбора вместо одиночного меню. В режиме выбора обычный тап добавляет/убирает книгу из набора.
- Множественный выбор работает во всех представлениях библиотеки: Grid, Compact, List, внутри папок и сгруппированных разделов.
- Верхняя панель режима выбора получила команды: выбрать все видимые книги, добавить выбранные в папку, переместить выбранные и удалить выбранные.
- Массовые copy/move/delete реализованы в `LibraryRepository` как пакетные операции: список книг меняется один раз и persistence запускается один раз на операцию.
- Для одиночного и массового добавления/перемещения книг запоминается снимок `folderPaths`; в обычной панели библиотеки появляется Undo последней такой операции.
- Системная кнопка Back сначала закрывает режим множественного выбора и связанные диалоги.
- Кнопка `⋮` сохранена для одиночных действий с книгой; long-press папки по-прежнему открывает операции с папкой.
- Исправлено задвоение кнопки Speed Reader в строковом представлении карточки книги.
- Добавлены alpha.33 self-check guards для multiselect, batch repository API, Undo и отсутствия задвоенного действия.
