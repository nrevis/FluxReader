# Flux Reader 0.2.0-alpha.22 — whole-line paging

Главное изменение — обычная читалка теперь делит экран как книжный ридер: только на целые полностью видимые строки.

Высота страницы сначала переводится в целочисленный line budget. При конфигурации, где помещаются 27 полных строк, пагинатор использует 27; размер шрифта, межстрочный интервал и вертикальные поля автоматически пересчитывают это число. Остаток в несколько пикселей снизу не используется для частичной 28-й строки.

После расчёта сетки каждая потенциальная последняя строка дополнительно проверяется по реальному `TextLayoutResult`. Если шрифт или метрики устройства делают её хоть немного выше доступной области, строка переносится на следующую страницу. Поэтому предпочтение всегда отдаётся меньшему количеству полностью отрисованных строк, а не обрезанному тексту.
