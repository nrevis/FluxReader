# Flux Reader 0.2.0-alpha.28

- Постраничный режим больше не отбрасывает остаток высоты из-за жёсткой сетки номинальных строк. Граница страницы выбирается по фактическому `TextLayoutResult.getLineBottom()`: если следующая строка помещается целиком, она используется; если нет — переносится полностью.
- Убрано глобальное ограничение числа строк, которое особенно заметно недозаполняло страницы с крупными заголовками и шрифтами, чьи реальные метрики отличались от номинальной высоты строки.
- Заголовок главы по умолчанию заметнее: `TITLE` — ExtraBold, `HEADING` — Bold, с принудительным синтезом веса для пользовательских гарнитур без отдельного bold-файла.
- EPUB: восстановление семантики для книг, где `Глава N` и название главы оформлены обычными `<p>` через CSS. В начале главы такие строки автоматически повышаются до `HEADING`/`TITLE`.
- Основная локальная установка переведена на non-debuggable `release` APK. Для совместимости с уже установленными alpha-сборками используется тот же локальный Android debug certificate; `install.command` устанавливает release через ADB.
- Добавлены `scripts/build-release.command` и `scripts/install-release.command`.
- Self-check расширен проверками measured pagination, жирных заголовков, EPUB heading recovery и release-сборки.
