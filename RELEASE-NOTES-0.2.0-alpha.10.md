# Flux Reader 0.2.0-alpha.10 — release notes

This build turns the home screen into a real book library rather than a simple imported-file list. Books can now be viewed as a cover grid or list, searched, sorted, grouped into user collections, grouped automatically by author or series, and edited without re-importing the original file.

Smart Import reads common EPUB and FB2 metadata, series numbers and embedded covers, while SHA-256 duplicate detection avoids accidental copies. Covers can also be replaced manually. Large cover previews are downsampled to keep the grid memory-friendly.

Reader appearance is expanded with popular built-in themes, a precisely adjustable named custom theme, and None/Slide/Fade/Zoom page-turn effects. Speed Reader receives additional visual presets and an optional focus band while retaining the alpha.9 long-word/ORP fixes and JetBrains Nerd font support.
