# Flux Reader 0.2.0-alpha.31

- Общие настройки: индикаторы скрытых вкладок стали минималистичными — без круглой подложки, рамки, elevation и тени; оставлены только компактные полупрозрачные стрелки.
- Направленные иконки настроек/библиотеки переведены на AutoMirrored, чтобы убрать deprecation warning и корректно поддерживать RTL.
- Deprecated `ClickableText` удалён: Reader и Speed Reader используют `BasicText` + точное определение позиции тапа через `TextLayoutResult`, сохраняя переход по ссылкам и запуск скорочтения с выбранного слова.
- Аннотированный текст ссылок и Speed-контекста кэшируется через `remember`, чтобы не пересобираться при лишних recomposition.
- Первый проход по памяти: bitmap-cache иллюстраций теперь рассчитывается от memory class устройства и ограничен диапазоном 12–32 MiB вместо фиксированных 48 MiB.
- Кэш структуры книг ограничен четырьмя книгами; кэш глав теперь учитывает примерный размер текста/объектов и имеет динамический лимит 2–8 MiB.
- При возврате в библиотеку reader-кэши подрезаются; тяжёлые PDF/OCR ресурсы освобождаются, а Tesseract backend можно восстановить по требованию.
- PDF text/OCR string caches уменьшены; AndroidX PDF держит открытым только один активный документ.
- Максимальный bitmap PDF ограничен 8 млн пикселей вместо 12 млн, что снижает worst-case пиковую память примерно с 48 до 32 MiB для ARGB_8888.
- Устаревшие результаты фонового PDF render теперь сразу recycle, а заменённые bitmap освобождаются после того, как Compose перестаёт ими пользоваться.
- Превью обложек библиотеки ограничены 640 px и продолжают использовать RGB_565.
- Добавлен `scripts/profile-memory.command` для реальных замеров PSS/RES/CPU на подключённом Android-устройстве.
- Убрана дублированная ветка/throw в prefetch-коде BookContentRepository.
