# Flux Reader 0.2.0-alpha.53

- Аннотации получили поиск по тексту, заметкам и книгам.
- Добавлены области «Эта книга» и «Все книги».
- Добавлена сортировка по дате, книге и главе.
- Текущую выборку аннотаций можно экспортировать в Markdown или TXT через Android document picker.
- Новая заметка на выделении хранится непосредственно в highlight, без второй дублирующей NOTE-аннотации.
- Любой highlight/quote может иметь собственную заметку и редактироваться из списка или popup над текстом.
- Для существующего выделения добавлено редактирование границ с уже имеющимися selection handles и сохранением диапазона через updateRange().
- Глобальный список аннотаций умеет открыть другую книгу сразу в сохранённой позиции.
