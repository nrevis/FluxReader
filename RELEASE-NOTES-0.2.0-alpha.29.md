# Flux Reader 0.2.0-alpha.29

В постраничном режиме появилась новая анимация `Лист`: страница приходит с внешнего края с перспективой, небольшим поворотом и тенью, затем укладывается плоско. Это не bitmap-эффект, поэтому текст остаётся чётким, масштабируемым и доступным. На непрерывной прокрутке тот же preset становится более спокойным боковым переходом без фальшивого «шарнира».

Переход в полноэкранный режим и возврат обратно теперь тоже анимируются по умолчанию. Эффект можно полностью отключить в расширенных настройках чтения; там же регулируется его длительность.

Для пользователей, у которых раньше оставалась стандартная анимация `Сдвиг`, она мигрирует на новый режим `Лист`. Явно выбранные `Нет`, `Fade` и `Zoom` не меняются.
