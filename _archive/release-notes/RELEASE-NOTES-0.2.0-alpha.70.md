# Flux Reader — 0.2.0-alpha.70

## Голосовое чтение

В Reader (EPUB / FB2 / TXT) появилась кнопка озвучивания. В панели доступны запуск, пауза, остановка, переход между предложениями, настройки скорости (0.6–1.4×) и высоты тона, выбор и прослушивание установленных голосов Android. Качество голосов определяется установленным TTS-движком. Для русских книг нужен установленный русский голос; приоритет по умолчанию отдан офлайн-голосам. Сетевые голоса отмечены и могут отправлять текст поставщику синтеза.

Позиция озвучивания сохраняется по текущему блоку текста. Между предложениями добавлены короткие паузы; при включённом соответствующем параметре после окончания главы запускается следующая. Поддержка паузы внутри предложения зависит от того, сообщает ли TTS-движок текущий диапазон символов.

Нейросетевой синтез через отдельного облачного провайдера, гарантированное воспроизведение в фоне с уведомлением, синхронная подсветка слов и озвучивание PDF пока не реализованы. Это первая версия новой подсистемы.

Сборка совместима по package ID и не требует очистки библиотеки. Опция экспериментального дизайна работает как прежде.
