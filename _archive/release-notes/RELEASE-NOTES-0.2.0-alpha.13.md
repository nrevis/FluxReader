# Flux Reader 0.2.0-alpha.13 — release notes

This build turns Speed Reader into a more focused reading surface. The new full-screen button enters an immersive Android mode: status/navigation bars, title, WPM sliders, mode chips and settings chrome disappear. Only previous sentence, Play/Pause, next sentence and exit-full-screen remain, with the optional thin book progress indicator.

Smart Speed 3.0 adds semantic sentence navigation, adaptive PHRASE/FOCUS chunk sizes, pause context and automatic sentence rewind after a long interruption. The rewind threshold is configurable, and all of these behaviors can be disabled independently.

Three content presets — Fiction, Study and Technical — provide useful smart-pacing starting points while preserving the user's selected WPM and visual settings.
