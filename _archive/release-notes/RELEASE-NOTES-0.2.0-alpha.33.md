# Flux Reader 0.2.0-alpha.33 — release notes

Версия развивает файловый менеджмент библиотеки.

## Главное

Теперь можно зажать книгу и перейти в режим множественного выбора. После этого обычными тапами отмечаются дополнительные книги, а верхняя панель позволяет массово добавить их в папку, переместить или удалить. Команда «выбрать всё» действует на текущий видимый набор, а Back закрывает режим выбора.

Copy/move больше не выполняются как серия отдельных сохранений. Репозиторий применяет пакетное изменение за один проход, что уменьшает лишнюю работу на больших библиотеках. Последнее одиночное или массовое изменение расположения книг можно отменить кнопкой Undo в библиотеке.

Одиночные действия `⋮`, редактирование метаданных, экспорт, дубликат и управление папками остаются доступны как раньше.

## Совместимость

- Android 9+ (`minSdk 28`)
- target/compile SDK 37
- EPUB / FB2 / FB2.ZIP / TXT / PDF
- офлайн-ветка без обязательного INTERNET permission
