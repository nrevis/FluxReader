# Flux Reader 0.2.0-alpha.52

Этот проход доводит взаимодействие с выделениями после alpha.51.

## Выделение у края экрана

В Scroll Reader выделение больше не упирается в видимый экран: при удержании пальца или ручки у верхнего/нижнего края запускается мягкая автопрокрутка. В Screen Paging то же действие переносит выделение на соседнюю страницу, сохраняя диапазон и оставляя его доступным для дальнейшего уточнения ручками.

## Работа с уже сохранёнными аннотациями

Обычный тап по существующему highlight/цитате/заметке/закладке открывает компактное меню около самого текста. Из него можно скопировать фрагмент, добавить или изменить заметку, сменить цвет highlight и удалить запись. Удаление требует подтверждения.

Ссылки EPUB обрабатываются первыми, поэтому сохранённая подсветка поверх ссылки не ломает переход по ссылке.
