# Flux Reader 0.2.0-alpha.46

This build focuses on Reader fullscreen stability and contextual speed-reading actions.

The current page stays visible during fullscreen reflow, the exact reading anchor is preserved when chrome changes, and the old fullscreen snap-to-line behavior is gone. The normal Reader now uses a compact red-outline speed icon. Tap a word in normal reading to highlight it and launch speed reading from that word through the contextual action.
