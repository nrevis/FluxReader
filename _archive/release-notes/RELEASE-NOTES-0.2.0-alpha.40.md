# Flux Reader 0.2.0-alpha.40

Системный UI/stability pass.

## Библиотека

- Long press снова означает «действия с книгой», как и для папок.
- Мультивыбор включается отдельной кнопкой; внутри режима обычный тап добавляет/убирает книгу.
- Back и крестик закрывают режим выбора даже при 0 выбранных.
- Массовые операции заблокированы при пустом выборе.
- У карточек удалены лишние callback-параметры, которые не использовались.

## Общий UI

- Одинаковые switch/slider primitives глобальных настроек и Speed Reader сведены в один компонентный слой.
- Повторный аудит fullscreen не обнаружил новых дублей: вход/выход остаются отдельными действиями разных состояний, а системные bars обслуживаются одним effect из alpha.39.

## Reader stability

- Устаревшая пагинация после rotation/fullscreen/viewport change отбрасывается по актуальному layout key до публикации и до записи в LRU.
- Добавлен отдельный regression/unit guard для stale layout commit.
