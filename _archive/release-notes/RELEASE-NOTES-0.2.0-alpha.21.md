# Flux Reader 0.2.0-alpha.21 — continuity & pagination pass

Эта сборка продолжает исправления alpha.20 и концентрируется на плавности чтения. Reader заранее прогревает соседние главы и держит несколько уже рассчитанных экранных разметок в небольшом LRU-кэше, поэтому возврат назад и переходы по уже открытым главам должны требовать заметно меньше повторной работы.

Физическая пагинация стала типографически аккуратнее: она старается не оставлять одну первую строку нового абзаца внизу страницы, не выносить одиночную последнюю строку абзаца на следующую страницу и не оставлять заголовок без хотя бы двух строк последующего текста. Существующая защита от разрыва слова и от подрезания нижней строки сохранена.

Speed Reader теперь рассчитывает вертикальную точку фиксации из фактической высоты основного текста и нижнего сегмента/контекста. Направляющие используют эту же точку, а место для pause-context резервируется заранее, поэтому переход в паузу не должен заставлять основной сегмент прыгать.

Обновление через `adb install -r` сохраняет библиотеку, настройки и прогресс чтения.
