# Flux Reader 0.2.0-alpha.18 — Library Manager

The library now behaves much more like a managed file browser.

Books can be copied to another virtual folder without duplicating storage, moved, physically duplicated, exported, renamed through metadata, or deleted with confirmation. Folders can be created empty, renamed, copied, moved, nested, or safely deleted while preserving their contents.

This release keeps the alpha.17 measured screen pre-pagination unchanged.
