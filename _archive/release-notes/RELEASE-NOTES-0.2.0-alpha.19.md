# Flux Reader 0.2.0-alpha.19 — UI Polish

Эта версия не меняет рабочую пагинацию alpha.17 и файловые операции alpha.18. Основная задача — сделать Flux Reader спокойнее, чище и быстрее для визуального считывания.

Главное: более лаконичная библиотека, скрываемые фильтры, меньше кнопок на карточках, компактные меню с иконками, единые скругления/типографика, менее перегруженный Reader и упрощённый Speed Reader.
