# Flux Reader 0.2.0-alpha.58

This build makes the two experimental interfaces visually unmistakable.

**Wasteland CRT** now has textured rust/metal wear, amber terminal framing, bolts, stronger CRT scanlines, bevelled industrial controls and its own custom icon family.

**Cyberpunk** now has its own micro-grid/circuit texture, brighter HUD perimeter, cyan/magenta/violet rails and an independent angular icon family.

The new artwork is static and non-interactive, so it does not add a permanent animation/recomposition loop or steal Reader gestures.
