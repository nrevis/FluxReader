# Flux Reader 0.2.0-alpha.30

Небольшая UX-итерация общих настроек. Вкладки больше не выглядят обрезанными без подсказки: у края появляется стрелка, когда есть скрытые пункты слева или справа. Вкладки отделены от параметров горизонтальной линией. Раздел «О программе» теперь показывает актуальную версию, автора n.revis и кратко перечисляет ключевые возможности приложения.
