# Flux Reader 0.2.0-alpha.26

Эта версия упрощает ежедневные настройки чтения и убирает точные параметры с основного экрана.

В Speed Reader размер текста теперь меняется прямо в главном окне настроек, а точная ORP-геометрия остаётся в `Расширенные`.

В обычной читалке верхнее и нижнее поля регулируются отдельно. Заголовки главы получили отдельный масштаб и центрирование, причём одно и то же форматирование применяется в обычном и полноэкранном режимах. Тап по названию книги открывает оглавление.

Постраничный режим учитывает асимметричные поля при расчёте целого числа строк и не пытается втиснуть частично видимую последнюю строку.
