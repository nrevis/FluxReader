# Flux Reader 0.2.0-alpha.43

Формы библиотеки теперь ведут себя одинаково: навигационные диалоги закрываются через «Закрыть», формы используют «Отмена» и явное подтверждение, а клавиатура получает предсказуемые действия Search / Next / Done. Переименование папки сразу выделяет существующее имя, редактор метаданных не сохраняет пустое название и закрывает IME перед системным выбором обложки.
