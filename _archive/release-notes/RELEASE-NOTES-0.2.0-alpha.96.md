# Flux Reader 0.2.0-alpha.96 — экспериментальное скорочтение диалогов

Новый режим перенесён на актуальную alpha.95. Сохранены обновления через GitHub, восстановление позиции при смене полноэкранного режима и общая позиция чтения Reader / Speed Reader / озвучки.

## Новый режим

- Определение прямой речи с тире и парными кавычками рядом с речевой ремаркой.
- Имя говорящего над точкой фиксации, когда оно явно следует из текста; иначе нейтральная плашка.
- Короткие реплики из 2–6 слов могут показываться целиком; длинные остаются в пословном RSVP.
- Дополнительная настраиваемая пауза 0–500 мс в начале реплики.
- Локальная обработка без сети и изменения исходного текста книги.

**Включение:** Настройки → Скорочтение → Экспериментальные функции → Распознавание диалогов; либо «Эксперимент: диалоги» в настройках Speed Reader. По умолчанию функция выключена.

Распознавание эвристическое: неявные говорящие не угадываются; некоторые нестандартно оформленные реплики могут остаться без выделения.

## Версия и установка

Версия APK: **0.2.0-alpha.96**, Android versionCode **20113**, пакет `io.fluxreader.app`, Android 9 и новее. Используется прежний локальный сертификат подписи для обновления поверх предыдущих alpha-сборок.

Номер alpha.92 в локальном экспериментальном проекте был унаследован от старой копии и не обновлён при добавлении диалогов. Для публикации исправлены метаданные Gradle, VERSION.txt, build-info и установщик. Проверка версии теперь отклоняет номер ниже существующих тегов и новый выпуск без увеличенного versionCode.

В релизе доступны готовый APK, ZIP исходников и SHA-256. Модели Tesseract rus/ukr/eng в эту сборку не вложены; сохранён резервный ML Kit Latin OCR.
