# Flux Reader 0.2.0-alpha.50

This build stabilizes Speed Reader gestures and starts the persistent text-annotation layer. Normal and fullscreen Speed Reader now share one tap map: single tap controls playback and double tap switches fullscreen. In the regular Reader, long-press and drag selects a range inside the current paragraph; saved highlights, quotes, notes and bookmarks remain available across app restarts and can be reopened from a dedicated annotations sheet.
