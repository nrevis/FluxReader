# Flux Reader 0.2.0-alpha.94

- Исправлено сохранение места чтения при входе в полный экран и выходе из него, включая последовательные изменения размеров экспериментальных оболочек Wasteland и Cyberpunk.
- Содержимое читалки остаётся в одном узле интерфейса при переключении панелей. Текстовая позиция закрепляется между пересчётами страниц, пока пользователь сам не перелистнёт страницу.
- Добавлена регрессионная проверка повторных переходов между несколькими размерами страницы и проверка смены главы.
- README заменён структурированным обзором возможностей и галереей из 52 скриншотов по функциям.
