# Flux Reader 0.2.0-alpha.23 — Reedy-style Speed Reader

В этой версии Speed Reader заметно перестроен в сторону поведения Reedy, но без копирования его интерфейса один в один.

Главное изменение — фиксация ORP. Подсвеченная буква теперь привязана к точному центру направляющей по реальному измерению текста, а не приблизительно через две равные половины Row. Поэтому короткие и длинные слова больше не должны визуально гулять вокруг точки фокуса. Само слово естественно находится левее ORP, а справа можно видеть несколько следующих слов приглушённым серым — они дают периферийный контекст, но не двигают текущую фиксацию.

Из обычной читалки можно выбрать `Скорочтение с выбранного слова`, затем коснуться любого слова на странице. Reader переводит этот тап в точное символьное смещение главы и открывает Speed Reader непосредственно с выбранного слова. Это работает и в прокрутке, и в подготовленном постраничном режиме.

Во время Speed Reader экран теперь принудительно остаётся включённым. Прогресс можно показывать по текущей главе, по всей книге или двумя полосами одновременно; новым значением по умолчанию стал прогресс главы.
