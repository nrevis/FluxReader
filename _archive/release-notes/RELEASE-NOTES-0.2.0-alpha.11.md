# Flux Reader 0.2.0-alpha.11 — release notes

This build makes Speed Reader less mechanical and makes application appearance genuinely adaptive.

The new Smart pacing mode preserves the selected WPM as a baseline but gives long or visually complex words more time, short words less time, and adds semantic pauses at clauses, sentence endings, and paragraph boundaries. Deep mode increases those comprehension-oriented adjustments; Constant mode retains strict fixed timing. PHRASE/FOCUS chunking now respects semantic boundaries, common Russian abbreviations are protected from false sentence breaks, and ORP placement ignores leading quotation/bracket punctuation.

Appearance now has two independent choices: palette and light/dark behavior. System follows Android, while Light and Dark lock the app to the chosen appearance. Rosé Pine Moon follows the official Moon colors in dark mode and Rosé Pine Dawn in light mode. CMX Purple uses the existing CMX Purple palette in dark mode and a derived high-contrast light companion. Existing palettes also have both light and dark schemes.

The Library app bar gets a fast System/Light/Dark switch, Speed Reader can inherit the app theme, and the interface uses more Material icons for scanning and navigation.
