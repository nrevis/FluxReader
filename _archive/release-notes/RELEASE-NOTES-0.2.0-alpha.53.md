# Flux Reader 0.2.0-alpha.53

Этот проход превращает заметки и выделения в отдельный рабочий слой Reader. В одном экране доступны текущая книга или вся библиотека, поиск, фильтры, сортировка и экспорт. Существующее выделение можно открыть на странице и поправить его границы ручками. Новые заметки теперь прикрепляются непосредственно к выделенному диапазону, а старые NOTE-записи остаются совместимыми.
