# Flux Reader 0.2.0-alpha.65

The previously automatic experimental redesign is now **opt-in**.

Open Settings → Appearance and enable **Экспериментальный дизайн** before selecting Wasteland CRT or Cyberpunk. If disabled, any selected palette uses the standard Flux screen geometry, navigation, icons and controls. Existing users are migrated to **off**, and their books are not touched.

Build/install:
`./FluxReader-0.2.0-alpha.65-build-install.command`
