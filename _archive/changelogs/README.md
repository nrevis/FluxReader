# Архив CHANGELOG

Исторические записи отсортированы по номерам версий. В оглавлении сначала идут новые версии; промежуточные выпуски `.1` и `.2` расположены рядом с основным выпуском.

Числовой префикс в имени файла задаёт порядок сортировки в GitHub: `006.000` → `009.000` → `010.000`, `013.000` → `013.001` → `013.002`. Исходное имя и номер версии сохранены после префикса; содержимое записей не изменено.

Архив не включается в пакеты выпусков и публикацию сайта.
