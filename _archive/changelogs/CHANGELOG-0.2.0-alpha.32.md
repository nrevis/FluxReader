# Flux Reader 0.2.0-alpha.32

- В общих настройках левый/правый overflow-индикатор теперь занимает собственную 34dp боковую зону. Вкладки физически сдвигаются от стрелки и больше не проходят под ней, сохраняя минималистичный вид без рамки и фона.
- Библиотека получила long-press management: долгое нажатие по книге в Grid / Compact / List открывает существующее меню действий.
- Долгое нажатие по папке открывает меню папки с созданием подпапки, переименованием, копированием, перемещением и удалением.
- Кнопки `⋮` сохранены, поэтому действия доступны и явным тапом, и привычным долгим нажатием.
- Существующая векторная иконка Flux Reader увеличена: книга занимает больше площади, при этом сохранён тот же единый тёмный фон и прежняя стилистика.
- Добавлены self-check guards на reserved tab rails, long-press handlers и геометрию исходной иконки.
