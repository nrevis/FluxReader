# Flux Reader 0.2.0-alpha.50

- Unified Speed Reader tap contract: single tap toggles playback; double tap toggles fullscreen in both layouts.
- Media cues keep local tap ownership; loading/error/chapter-intro states ignore playback taps.
- Added long-press + drag range selection inside Reader text blocks.
- Added persistent highlights, quotes, notes and bookmarks in a reader-owned JSON store.
- Added Reader annotations sheet with jump/edit/delete actions.
- Added selection actions: Speed from selection, copy, colored highlight, quote, note, bookmark and search.
