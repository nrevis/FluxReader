# Flux Reader 0.2.0-alpha.22

## Reader — целочисленная сетка страницы

- Screen Paging переведён с свободной пиксельной высоты на сетку из целого количества полностью видимых строк.
- `ReaderPageGridCalculator` вычисляет доступный бюджет строк из реальной высоты viewport, вертикальных полей, нижнего safety reserve и текущей высоты строки.
- Дробный остаток высоты больше не используется для попытки дорисовать ещё одну строку: он остаётся пустым внизу страницы.
- При текущей геометрии, где помещаются 27 строк, этот бюджет остаётся 27; увеличение шрифта, line-height или вертикальных полей уменьшает число строк, уменьшение — может увеличить.
- На каждой странице действует двойная проверка: число строк не превышает budget, а `TextLayoutResult.getLineBottom()` после округления вверх обязан полностью помещаться в доступную высоту.
- Если последняя строка не помещается целиком, пагинатор показывает на одну строку меньше вместо визуального обрезания.
- Paragraph spacing, заголовки и widow/orphan правила alpha.21 по-прежнему могут уменьшить фактическое число строк на конкретной странице.

## Тесты

- Добавлен `ReaderPageGridTest`: проверка 27 строк для контрольной геометрии, уменьшения бюджета при крупном шрифте/полях и ограничения измеренного layout остатком line budget.
- Pure-Kotlin helper не зависит от Android/Compose и может проверяться отдельно.
