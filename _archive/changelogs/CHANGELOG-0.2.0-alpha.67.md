# Flux Reader 0.2.0-alpha.67 — Wasteland / Cyberpunk Chrome

- Реализован самостоятельный Cyberpunk-корпус (полноэкранный HUD), панели и нижняя навигация с собственными обработчиками, без наложенных невидимых кнопок.
- Для обоих экспериментальных режимов: тематические папки, навигационные крошки, меню папок и книжные карточки в GRID/COMPACT/LIST.
- Reader, PDF Reader, Speed Reader и настройки используют отдельно стилизованные top bar, контролы, вкладки и прогресс.
- Новые уникальные Android VectorDrawable для папок Wasteland и Cyberpunk (реальные XML-ресурсы, не макеты).
- Экспериментальная оболочка включается ИСКЛЮЧИТЕЛЬНО когда `experimentalDesignEnabled = true` и выбрана соответствующая тема.
- Без галочки сохраняются прежние экраны, обработчики и настройки; книги/позиции чтения не меняются.
- Декоративные текстуры в wrap-content панелях используют `matchParentSize`, чтобы не растягивать контейнеры и не перекрывать управление.

Ограничение: статический selfcheck не эквивалентен Android/Kotlin build; компиляция должна быть подтверждена на машине с Android SDK.
