# Flux Reader 0.2.0-alpha.30

- Общие настройки: добавлены краевые стрелки-индикаторы для горизонтально прокручиваемых вкладок. Стрелка появляется только если с соответствующей стороны есть скрытые разделы и также прокручивает ряд по нажатию.
- Ряд вкладок визуально отделён от содержимого настроек горизонтальной линией.
- «О программе»: версия и build, автор `n.revis`, короткое описание форматов и возможностей Flux Reader.
- Self-check дополнен guards для overflow-индикаторов, разделителя и About-метаданных.
