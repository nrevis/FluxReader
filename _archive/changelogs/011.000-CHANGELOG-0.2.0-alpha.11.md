# Flux Reader 0.2.0-alpha.11

Smart Speed + adaptive light/dark themes + icon pass.

- Added independent appearance mode: System / Light / Dark. System follows Android at runtime.
- Added Rosé Pine Moon with the official Moon palette and Rosé Pine Dawn as its light companion.
- Added CMX Purple using the project's existing CMX Purple dark palette, plus a high-contrast light companion.
- Added light counterparts for the existing built-in palettes so palette choice and light/dark appearance are independent.
- Added a one-tap System → Light → Dark appearance toggle to the Library app bar.
- Speed Reader can follow the application color scheme or keep its own colors.
- Added Rosé Moon, CMX Purple, and Dawn Speed Reader presets.
- Added Constant / Smart / Deep pacing modes.
- Smart/Deep pacing adapts dwell time to token length, digits, acronyms, URLs, punctuation, sentence endings, and paragraph boundaries.
- Smart phrase chunking now really stops on sentence/clause/paragraph boundaries instead of continuing the repeat loop.
- Common abbreviations and initials no longer create false sentence pauses.
- ORP focus skips opening punctuation and lands on a lexical character.
- Added smart-speed controls both to Settings and the Speed Reader sheet.
- Expanded Material icon use across Settings, Library search/sort/group controls, appearance switching, and Speed Reader navigation/actions.
