# Flux Reader 0.2.0-alpha.27.1

## Build fix

- Исправлен вызов Compose `Modifier.padding` в постраничном рендерере изображений: `horizontal` больше не смешивается с `top`/`bottom` в одном несовместимом overload.
- Горизонтальные поля и отдельные верхнее/нижнее поля сохранены без изменения поведения — теперь применяются двумя последовательными `padding()`.
- Добавлен static self-check, который сканирует Kotlin-исходники и не допускает повторного появления этой формы `padding(horizontal=..., top/bottom=...)`.
- Сохранены обе монохромные темы alpha.27 и исправленный Gradle Wrapper из alpha.26.1.
