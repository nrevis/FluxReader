# Flux Reader 0.2.0-alpha.35

- Убран самый дорогой hot-path большой библиотеки: сохранение позиции чтения больше не пересобирает и не сортирует весь список книг при каждом изменении страницы/прогресса. Меняется только одна запись; выбранная сортировка применяется в UI библиотеки.
- Декодирование обложек вынесено из Compose/main thread в `Dispatchers.IO`. Добавлен ограниченный LRU-кэш превью, размер которого зависит от memory class устройства.
- Для компактных карточек и списка используются меньшие preview buckets, поэтому сетка библиотеки расходует меньше памяти и быстрее заполняется при быстром скролле.
- Поиск библиотеки получил предварительно нормализованный индекс: lowercase/группы/серии/пути готовятся один раз на snapshot библиотеки, а не заново на каждый введённый символ.
- Блок «Продолжить» теперь вычисляется через `remember(books)`, без повторного полного прохода при несвязанных recomposition.
- Prefetch соседних глав стал адаптивным: 1 глава на low-memory устройствах, 2 на обычных и до 3 на устройствах с большим memory class.
- При переходе из библиотеки в reader/PDF/speed-reader кэш обложек автоматически ужимается до четверти, освобождая память под текст, изображения и PDF bitmap; при уничтожении ViewModel кэш полностью очищается.
- Добавлены regression guards и unit tests для search index, cover-memory budget и adaptive prefetch radius.
