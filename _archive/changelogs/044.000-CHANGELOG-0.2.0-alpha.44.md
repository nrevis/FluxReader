# Flux Reader 0.2.0-alpha.44

- Fullscreen Speed Reader now reserves a dedicated bottom control area so the pause-context card never sits beneath playback controls.
- The same reserve participates in fixation geometry, protecting the ORP word from lower chrome.
- Playback controls use a stronger floating surface with border/shadow and a larger primary Play/Pause action.
- Pause context uses a denser elevated card with improved text contrast.
- Progress/HUD contrast was increased without adding duplicate controls.
- Version bumped to `0.2.0-alpha.44` / `20059`.
