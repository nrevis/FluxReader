# Flux Reader 0.2.0-alpha.29

- Добавлен новый режим анимации страниц `Лист` (`PageTurnAnimation.CURL`) с перспективой, привязкой к внешнему краю страницы, небольшим поворотом и мягкой тенью — как лёгкая имитация физического перелистывания без растрирования текста.
- Для постраничного режима `Лист` стал новым значением по умолчанию. Старый дефолт `Сдвиг` автоматически мигрирует на `Лист`, при этом явно выбранные `Нет`, `Fade` и `Zoom` сохраняются.
- Межглавные переходы в постраничном режиме тоже получают ту же направленную анимацию, а не переключаются мгновенно.
- Добавлена анимация входа в полноэкранное чтение и выхода из него: лёгкое масштабирование, смещение и fade. Включена по умолчанию.
- В `Расширенные → Навигация` добавлены переключатель `Анимация полного экрана` и точная настройка её длительности (100–600 мс).
- Диапазон длительности анимации страниц расширен до 700 мс; для нового режима `Лист` дефолтная длительность — 260 мс.
- Self-check дополнен guard-проверками `CURL`, perspective/rotation и persisted fullscreen transition settings.
