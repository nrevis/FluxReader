# Встроенная озвучка · alpha.104

В меню «Голос и озвучка» (Speed Reader) или «Озвучивание книги» (обычное чтение) выберите «Встроенные», затем «Скачать голоса». Перед загрузкой доступны условия OpenRAIL-M. После загрузки выберите один из десяти голосов и нажмите «Проба голоса». Пакет предназначен прежде всего для русского текста.

## Компоненты

- sherpa-onnx **v2.0.0**, исходный commit `8abb7c8f87eae85b2e75f9a4115236c978980add`, Apache-2.0. Официальный Kotlin API находится в `app/src/main/java/com/k2fsa/sherpa/onnx/Tts.kt` без изменений.
- Две нативные библиотеки (`libsherpa-onnx-jni.so`, `libonnxruntime.so`) для arm64-v8a, armeabi-v7a, x86 и x86_64. Архив скачивается при первой сборке, не хранится в Git и в ZIP исходников. Gradle проверяет SHA-256 `578650d0221255566bd7c88bd3a0deeb974b8562a332a6a875b35bd00b7e0f5d`.
- ONNX Runtime **1.28.2**, MIT. Лицензия и ThirdPartyNotices включены в APK.
- Supertonic 3 INT8, пакет `sherpa-onnx-supertonic-3-tts-int8-2026-05-11.tar.bz2`, 128 774 318 байт. SHA-256 `82fa96f91c4ef8abaae3a14a3f4153facf88bed821d1f7331cec2700f432c427`.
- Исходная модель Supertone: **OpenRAIL-M**, не следует путать с MIT-лицензией вспомогательного кода. Оба уведомления сохраняются при установке. Разработка исходной модели прекращена; используется закреплённый архивный выпуск через поддерживаемый runtime.
- Apache Commons Compress **1.28.0**, Apache-2.0, для чтения tar.bz2. Piper, piper-phonemize и eSpeak не включены.

## Данные и работа

Модели хранятся в `noBackupFilesDir/tts-models-v1`: они не попадают в облачную резервную копию Android. Загрузка начинается только после действия пользователя. Она переживает закрытие меню; после остановки процесса её можно повторить. Докачки с места прерывания пока нет.

Проверяются размер и полный SHA-256 архива, размеры обязательных файлов, пути и типы tar-записей. Установка идёт во временный каталог с атомарным перемещением. Символические ссылки, дубликаты, выход из каталога и слишком большой распакованный пакет отклоняются. Частично установленная модель не становится доступной.

Нативная модель загружается лениво, синтез выполняется вне UI-потока. Выделение памяти, синтез и освобождение защищены общим Mutex. WAV-кэш в cacheDir ограничен 64 МБ. Подготавливаются не более двух следующих фрагментов. Ни текст книги, ни фрагменты речи не отправляются в сеть.

Для JNI используется именованный типизированный callback: он сохраняет метод `invoke(float[]): Integer`, который ожидает sherpa-onnx. Совместимость проверяется отдельным JVM-тестом и реальным запуском Android. Обычная indy-лямбда Kotlin имеет другую сигнатуру и не подходит.

Скорость и высота применяются при воспроизведении независимо от синтеза. Пауза, переход к другой позиции, смена голоса и закрытие экрана отменяют ожидающее воспроизведение; устаревшая фраза не запускается после завершения синтеза. Удаление модели останавливает встроенное воспроизведение. При ошибке модель не заменяется молча голосом Android.

Синхронизация со страницей выполняется по исходным фразам и UTF-16 смещениям. Точного времени каждого слова эта модель не возвращает. Качество ударений, имён и интонации не гарантируется; скорость и память на реальном телефоне могут отличаться от эмулятора. Автоматического назначения разных голосов персонажам в этом выпуске нет.
