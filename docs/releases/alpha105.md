# Flux Reader 0.2.0-alpha.105

Улучшено определение говорящего без языковой модели и дополнительных загрузок.

- Текущая глава автоматически разбирается в фоне при включённых диалогах. Анализ всей книги остаётся дополнительной настройкой.
- Добавлены пропущенные глаголы речи и осторожное распознавание ремарок «начал/закончил».
- Разные говорящие в одном абзаце больше не получают имя первого персонажа.
- Продолжение монолога после авторского пояснения учитывает многоточия и подтверждающие ремарки с обеих сторон.
- Уход персонажа очищает контекст местоимений; имя из чужой цитаты не возвращает его в сцену.
- Кэш анализа пересчитывается. Изменение границ одной реплики не удаляет остальные корректные ручные правки.

На прежних 22 целях главы «Сюрпризы на день рождения»: 18 верных подписей, 0 ошибочных, 4 без имени (было 17/0/5). На отдельном замороженном наборе из 28 сцен устранена одна ложная подпись; 13 верных, 9 без имени и 6 корректно оставленных неоднозначных сцен. Это локальные контрольные выборки, а не оценка точности на всех книгах.

Проверено: 259 JVM-тестов, сборки debug/release и release lint. В эмуляторе Android 16 подтверждены пять реальных фрагментов книги при выключенном анализе всей книги. На локальной подборке из восьми книг проверены границы и поиск речевых диапазонов; это не измерение точности всех имён.
