# Flux Reader 0.2.0-alpha.110

Добровольная поддержка разработки.

В разделе «Настройки → О программе» появилась кнопка «Поддержать на Boosty». Она открывает страницу автора в браузере.

Flux Reader и все его функции остаются бесплатными. Поддержка добровольная: она помогает оплачивать программы, инструменты разработки и подписки на нейросети. Платёжных форм и платёжных SDK в приложении нет.

На GitHub добавлены кнопка Sponsor и информация о поддержке проекта.
