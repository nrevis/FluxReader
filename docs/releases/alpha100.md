# Flux Reader 0.2.0-alpha.100 — анализ диалогов всей книги

Добавлен экспериментальный предварительный анализ всей книги для маркировки говорящих. Чтение доступно сразу: текущая глава обрабатывается первой, затем остальные. Имена из явных авторских указаний собираются в общий список, результаты уточнения реплик сохраняются на устройстве.

- Поддерживаются EPUB, FB2 и TXT. Работа полностью локальная, прогресс виден в меню диалогов.
- Длинные скороговорки, склеенные дефисами, показываются читаемыми частями. Обычные дефисные слова остаются целыми.
- Предпросмотр на паузе показывает текущий абзац; можно переходить к слову внутри такой реплики.
- Исправлена перезапись выбранного слова началом главы при завершении загрузки. Проверено восстановление слова после полного закрытия приложения.

**Как включить:** Скорочтение → Эксперимент: диалоги → Анализ всей книги (эксперимент). Переключатель выключен по умолчанию.

**Ограничения:** первый вариант использует осторожные правила. Местоимения, смысловые роли и автоматическое объединение коротких и полных имён ещё не обрабатываются. При недостатке оснований сохраняется маркер «Прямая речь». PDF в анализ всей книги пока не входит.

**Проверки:** 202 unit-теста, проверки исходников, сборка release и проверка в Android-эмуляторе. На текстах восьми книг добавлено 34 подписи; это прирост охвата, а не оценка точности распознавания.

**Сборка:** 20117 · Android 9+ · подпись сохранена для обновления поверх предыдущих alpha-сборок с тем же сертификатом.

Во вложениях: APK, чистый архив исходников и SHA-256 для каждого файла. В исходниках нет локальных книг, ключей подписи и настроек окружения. Языковые модели Tesseract в этот APK не вложены.
