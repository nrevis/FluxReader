# Flux Reader 0.2.0-alpha.103 — цвета персонажей

Сборка 20120 на основе alpha.102.

- В «Эксперимент: диалоги → Цвета персонажей» доступен список найденных имён с поиском и переключателем автоматических цветов.
- Палитра из восьми читаемых цветов закрепляется за именами в книге. Первые восемь получают разные цвета, затем палитра повторяется; сохранённые назначения не меняются при смене главы, порядке обнаружения остальных имён или повторном анализе.
- Для каждого имени можно выбрать свой цвет либо вернуть общий/автоматический вариант. Быстрый доступ — нажатием имени → «Цвет имени в книге».
- Меняются цвет имени, контур и лёгкая заливка бабла; геометрия выбранной темы сохраняется. У светлого и тёмного фона разные оттенки той же палитры.
- Индивидуальный цвет действует во всей книге и имеет приоритет над общей настройкой. Неизвестный говорящий сохраняет нейтральный цвет темы.
- Цвета хранятся отдельно от разметки реплик. Их изменение не создаёт ручную коррекцию имени и не переписывает текст.

Варианты имён и прозвища пока не объединяются автоматически. Локальная LLM в эту сборку не включена.
