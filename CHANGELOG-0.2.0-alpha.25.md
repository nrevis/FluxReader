# Flux Reader 0.2.0-alpha.25

- Speed Reader теперь по умолчанию использует левую треть экрана как стабильную точку фиксации (30% ширины).
- ORP-буква, вертикальная направляющая и текущее слово используют одну и ту же горизонтальную координату.
- RSVP-слова по умолчанию отображаются одним фиксированным размером шрифта без скачков кегля между короткими и длинными словами.
- Серые следующие слова сохраняют тот же размер и продолжаются вправо от текущего слова, поэтому взгляд меньше перемещается.
- В «Расширенных» добавлены отдельные параметры «Одинаковый размер слов» и «Позиция точки взгляда».
- Автоподгонка длинных слов остаётся как опциональный режим и показывается только когда фиксированный размер отключён.
- Для RSVP основная строка теперь использует полную ширину viewport, чтобы направляющая и ORP не расходились из-за дополнительного внутреннего масштабирования.
- Добавлены regression-тесты горизонтальной точки фиксации и static self-check для новых настроек.
