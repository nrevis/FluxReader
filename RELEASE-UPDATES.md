# GitHub Updates — Flux Reader

Источник: https://github.com/nrevis/FluxReader/releases

В **Настройки → О программе → Обновления** можно проверить новые версии,
включить/отключить ежедневную проверку при запуске, выбрать alpha-канал,
посмотреть описание релиза, скачать APK и открыть системный установщик.
Офлайн-чтение и библиотека от сетевого сервиса не зависят.

## Формат релиза

- Тег: `v0.2.0-alpha.95` (или другая версия, совпадающая с `VERSION.txt`).
- GitHub Release должен быть **опубликован**, не draft.
- Asset: `FluxReader-0.2.0-alpha.95-release.apk` (не debug APK).
- Asset: `FluxReader-0.2.0-alpha.95-release.apk.sha256`, содержащий SHA-256 и имя APK.
  Если GitHub API сообщает `assets[].digest=sha256:<hex>`, приложение может
  использовать его вместо отдельного файла.
- `versionCode` в APK должен быть **строго выше** установленного.
- `applicationId` должен быть `io.fluxreader.app`.
- APK должен быть подписан **тем же сертификатом**, что установленная версия.

## Сборка и ручная публикация с Mac

```bash
cd ~/Downloads/FluxReader-0.2.0-alpha.95-clean
chmod +x gradlew scripts/*.command
./gradlew :app:testDebugUnitTest :app:assembleRelease
scripts/build-release.command
brew install gh  # если GitHub CLI ещё не установлен
# Выполнить gh auth login один раз
scripts/publish-github-release.command --publish
```

Для просмотра публикаций: `gh release list --repo nrevis/FluxReader`.
Для проверки доступности репозитория: `gh repo view nrevis/FluxReader`.
Скрипт публикации **не выполняется автоматически**.

### Важно: подпись

Текущий `build.gradle.kts` намеренно подписывает alpha-release локальным debug-keystore,
чтобы сохранить совместимость с предыдущими сборками. У **другой машины/CI**
будет **другой** debug-keystore; такой APK нельзя установить поверх старого.
Не публикуйте APK с непроверенной подписью. Для постоянных релизов лучше
перейти на отдельный безопасно хранимый release keystore, но переход на новый
сертификат потребует миграции (обычная установка поверх несовместима).

Сервис обновлений НЕ устанавливает пакеты без подтверждения пользователя и
НЕ обещает автоматическое обновление без участия Android Package Installer.
При первом использовании потребуется разрешить «Установку неизвестных
приложений» для Flux Reader. Источник APK проверяется по SHA-256, имени пакета,
номеру сборки и сертификату подписи.

Если в репозитории ещё нет опубликованного APK, приложение покажет, что
доступных обновлений нет. Если GitHub недоступен —
будет показана ошибка сети/HTTP, но приложение продолжит работать офлайн.

Репозиторий публичный. Для получения текущих тестовых выпусков включите «Включая тестовые alpha-релизы» в настройках обновлений и нажмите «Проверить».
