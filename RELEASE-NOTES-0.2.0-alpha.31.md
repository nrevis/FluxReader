# Flux Reader 0.2.0-alpha.31

Alpha.31 начинает отдельный этап оптимизации после переработки настроек. Стрелки скрытых вкладок теперь выглядят как лёгкие минималистичные индикаторы без обводки и подложки.

Одновременно убраны текущие Compose deprecation warnings для направленных иконок и `ClickableText`, не меняя поведение ссылок и выбора слова для Speed Reader. Первый memory-pass ограничивает image/chapter/outline/PDF/OCR caches, снижает максимальный PDF bitmap, освобождает устаревшие render-результаты и тяжёлые PDF/OCR ресурсы после выхода в библиотеку.

Для последующих сравнений добавлен `scripts/profile-memory.command`: он снимает `dumpsys meminfo`, RES/CPU процесса и путь установленного APK через adb.
