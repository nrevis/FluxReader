# Flux Reader 0.2.0-alpha.27

Монохромная итерация оформления. В разделе **Оформление → Палитра** появились `Ч/Б` и `Ч/Б мягкая`. Ни одна из них не использует цветовые акценты: активные элементы, ссылки, ошибки, индикаторы и элементы управления остаются в серой шкале. Визуальная иерархия строится прежде всего на жирности текста и контрасте поверхностей.
