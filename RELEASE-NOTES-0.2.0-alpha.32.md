# Flux Reader 0.2.0-alpha.32

Alpha.32 делает верхние вкладки настроек визуально понятнее: стрелки остаются лёгкими и без обводки, но теперь имеют собственное место и не сливаются с названиями вкладок.

Библиотека ведёт себя ближе к обычному файловому менеджеру Android: долгий тап по книге или папке вызывает меню операций. Кнопки `⋮` остаются доступными. Также без смены дизайна увеличена существующая иконка книги на едином тёмном фоне.
