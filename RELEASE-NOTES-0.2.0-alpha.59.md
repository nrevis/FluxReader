# Flux Reader 0.2.0-alpha.59 — Wasteland UI experiment

The Wasteland theme is now a real alternate interface implementation, modeled closely on the supplied rugged terminal reference: green CRT screen, amber controls, distressed metal framing, vents, screws, warning marks and hard-edged control plates.

The overhaul covers Library, normal Reader, PDF Reader, Speed Reader and Settings. The regular Flux Reader themes remain available and do not use the physical Wasteland shell.

This is deliberately an experimental UI layer. It reuses the real Flux Reader state/actions instead of replacing screens with mockups, so importing books, opening/reading, progress, settings, PDF navigation, Speed Reader and library management remain functional.
