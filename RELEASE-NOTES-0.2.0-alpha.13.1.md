# Flux Reader 0.2.0-alpha.13.1 — release notes

This is a build-only hotfix for alpha.13. It addresses the three Kotlin compiler errors reproduced on the user's macOS Android 37 setup: two unavailable Android XMLConstants fields and two invalid explicit Compose `weight` imports.

No reading behavior or Smart Speed 3.0 tuning was changed. The purpose of this build is to preserve alpha.13 functionality while making the project compile on the real Android toolchain.
