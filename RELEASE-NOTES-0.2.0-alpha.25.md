# Flux Reader 0.2.0-alpha.25

Эта версия делает Speed Reader визуально спокойнее. По умолчанию точка фиксации перенесена в левую треть экрана, а размер RSVP-текста зафиксирован. Красная ORP-буква остаётся на одной горизонтальной позиции, текущие слова не меняют кегль, а последующие слова видны серым справа.

Точная позиция точки взгляда, отключение фиксированного размера и аварийная автоподгонка оставлены в разделе «Расширенные».
