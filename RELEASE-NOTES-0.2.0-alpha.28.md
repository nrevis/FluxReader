# Flux Reader 0.2.0-alpha.28

Эта сборка исправляет лишнее пустое место снизу в постраничном чтении. Вместо заранее урезанной целочисленной сетки Flux Reader теперь использует всю безопасную высоту экрана и принимает последнюю строку только после проверки её реальной нижней границы. Поэтому страница заполняется плотнее, но обрезанной строки по-прежнему быть не должно.

Заголовки главы по умолчанию стали жирными и лучше распознаются даже в EPUB, где издатель оформил их обычными абзацами через CSS. Для таких книг последовательность вроде `Глава 16` + короткое название автоматически получает семантику заголовка.

`install.command` теперь строит и ставит non-debuggable release APK через ADB. Это убирает debug-флаг из устанавливаемой сборки. Play Protect всё ещё может предупредить о sideload-приложении неизвестного разработчика — полностью убрать репутационную проверку можно только через доверенный канал распространения/Play Console.
