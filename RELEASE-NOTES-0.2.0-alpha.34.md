# Flux Reader 0.2.0-alpha.34 — Reader polish

Эта сборка концентрируется на устойчивом чтении на полноэкранных Android-устройствах, прежде всего на экранах с центральным вырезом камеры.

Главное изменение — более консервативная подготовка физических страниц: последняя строка страницы получает дополнительный запас по реальным метрикам шрифта, а полноэкранный viewport имеет отдельные защитные поля. HUD прогресса больше не может пересекать центральную область hole-punch.

Прогресс книги теперь сохраняется не только по индексу блока, но и по символьному якорю внутри текстового блока. Это делает восстановление и отображение прогресса заметно стабильнее на книгах с длинными абзацами.

Также исправлен скачок до 100% при переходе в начало последней главы.
