# Flux Reader 0.2.0-alpha.20 — Reader + Speed Reader readability pass

Эта сборка исправляет две заметные проблемы чтения.

В обычной читалке автоматические переносы теперь выключены по умолчанию, поэтому Compose не должен вставлять визуальные дефисы внутрь слов. Экранная пагинация дополнительно резервирует нижнюю часть страницы по метрикам текущего шрифта, чтобы последняя строка не попадала под нижнюю границу/жестовую область.

В скорочтении вертикальная направляющая получила большую безопасную зону, а крупная фиксация больше не смещается из центра из-за дополнительной информации. Текущий сегмент можно держать постоянно под основным словом; также доступен режим с ближайшим контекстом. Умная многословная разбивка теперь старается не заканчивать фиксацию коротким союзом или предлогом.

Обновление через `adb install -r` сохраняет библиотеку, настройки и прогресс чтения.
